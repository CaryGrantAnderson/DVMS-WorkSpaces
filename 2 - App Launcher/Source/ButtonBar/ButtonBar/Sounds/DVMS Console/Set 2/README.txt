DVMS CONSOLE - ORIGINAL SOUND EFFECTS - SET 2

Set 2 is the deeper and more cinematic variation. It uses lower tuning,
additional synthesized bass, slower build-ups, longer durations, and a more
spacious echo than Set 1.

These sounds were procedurally synthesized specifically for the DVMS project.
They contain no samples from Star Trek or any other film, television program,
recording, sound library, or third-party work.
