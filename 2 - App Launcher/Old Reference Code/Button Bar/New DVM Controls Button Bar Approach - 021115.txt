New DVM Controls Button Bar Approach - 021115
=============================================
2/11/2015



The Problem:
----------------------------------------------------------------

1. My DVM controls need a very flexible header and footer system
   which can include:

	- Drop Down Menu Button.
	- Menu bar.
	- Button Bars.


2. Every control then can use the same approach (and code).

	- And this can be a DVM standard.




The Approach:
----------------------------------------------------------------

1. I need to have "bands" which I can:

	- Display and hide, 
	- Move between header and footer
	- Change the stacking position/order of multiple toolbars.

	- And let the power user control these as options.


The Base Design:
----------------------------------------------------------------

1. Header/Footer Panel that is docked to the top or bottom of the
   form.


1.1 Header Bar:
-------------------------------------------------
Header Name....		       DropDownMenuButton
-------------------------------------------------


1.2 Button Bar:
-------------------------------------------------
|Button 1||Button 2||Button 3||Button 4|
-------------------------------------------------

	Versions For:	Grid
			Tree
			Etc...

1.3 Nav Bar:
-------------------------------------------------
|<<||<||Record N of N||>||>>|
-------------------------------------------------


1.4 View Bar:
-------------------------------------------------
View:  [combobox]
-------------------------------------------------


1.5 Info Bar:
-------------------------------------------------
Info Label:  Status Label
-------------------------------------------------

	Example:  Tree node path.



1.6 Footer Bar:
-------------------------------------------------
Status Label		Date Time Label   X Label
-------------------------------------------------

	Example:  Row Count:....    Date Time    User ID



The Base Component - The Button Bar:
----------------------------------------------------------------

1. Flow Panel hosting buttons and labels with spacers as 
   necessary.

2. Add/Edit/Delete Item Collection of:

	- Buttons
	- DropDownButtons
	- Labels

3. Ability to regroup buttons by reordering the collection.




The Container Component - The Header/Footer:
----------------------------------------------------------------

1. Panel container control.

2. Dock in top or bottom of the parent container.

3. Only difference between Header and Footer is the name and 
   the default docking direction.

4. Ability to add and delete the button bars in the header/
   footer container.

5. Reordering is done by readding the button bars in the
   desired sequence.



The Simple and Direct Approach:
----------------------------------------------------------------

1. Hard code the button bars for now.

2. Defer creating individual button bar controls and header and
   footer containers.
